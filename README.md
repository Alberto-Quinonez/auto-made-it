# Auto Made It

## What does this app do?

Auto Made It is a simple desktop app that lets you open a CSV file and read its contents. A CSV (Comma-Separated Values) file is a common type of spreadsheet file that can be exported from programs like Microsoft Excel or Google Sheets.

When you load a file, the app reads each row and prints it to the terminal window so you can see the data.

---

## Before you start

You will need **Python** installed on your computer. If you are not sure whether you have it, open a terminal and type:

```
python --version
```

If you see a version number (e.g. `Python 3.11.0`), you are good to go. If not, download Python from [python.org](https://www.python.org/downloads/) and install it.

---

## How to run the app

1. Open a terminal (search for **Command Prompt** or **PowerShell** in the Start menu)
2. Type the following and press Enter:

```
cd C:\Users\test\dev\auto-made-it
```

3. Then type this and press Enter:

```
python main.py
```

A window will open — that's the app.

---

## How to use the app

1. Click the **Browse…** button
2. Find and select your CSV file
3. Click **Load & Print**
4. The contents of the file will be printed in the terminal window behind the app
